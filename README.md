# dreamitprintfinds.com

Link page for @dreamitprintfinds: 3D printed props and custom gifts from Limitless 3D Labs, 10% off with code DREAMITPRINT10.

Next.js (App Router) + TypeScript + Tailwind, deployed on Vercel. See `CLAUDE.md` for layout and rules.

```bash
npm install
npm run dev
```

Shop links live in `lib/links.ts` and are served through `/go/<slug>` redirects.
